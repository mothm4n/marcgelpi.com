# Personal Brand Website

This context defines the release language used to plan and assess Marc Gelpí's personal website.

## Language

**V0**:
The internal name for the published foundation that precedes the complete V1. The label is never presented to website visitors.
_Avoid_: Foundation Release, public beta

**V1**:
The first complete product milestone defined by the original website specification. Publishing an earlier subset does not redefine or complete V1.
_Avoid_: Current production site, V0

**Selected career history**:
The public chronology of Marc's recent and most relevant professional roles, with earlier experience summarized and an external profile available for additional detail.
_Avoid_: Complete career history, full CV
