# Use V0 for the published foundation

The site is already public, but it does not satisfy the original V1 scope because some planned journeys remain unfinished. We will call the published foundation **V0** internally, keep version language out of the visitor experience, and preserve the original V1 as the next complete milestone instead of rewriting it retrospectively to match the smaller release.

V0 comprises the published Home, Work, About, and Contact journeys. Writing and Resources remain outside the public navigation and belong to V1. V0 still requires the canonical HTTPS domain, working contact destinations, recorded editorial approval, and passing production acceptance; Search Console remains a V1 concern.
